# 🧹 Automated Data Cleaning Assistant

An intelligent data quality and cleaning application built with **Python, Pandas, and Streamlit**.

The application analyzes CSV datasets, detects data quality issues, classifies columns, calculates a data quality score, generates risk-based cleaning recommendations, and safely applies automated cleaning operations.

## 🚀 Features

- 📁 CSV dataset upload
- 🔍 Automated data profiling
- 🧠 Semantic column classification
- 🩺 Data quality scoring
- ⚠️ Risk and P1–P3 priority assessment
- 💡 Intelligent cleaning recommendations
- 🧹 Safe automatic data cleaning
- 📊 Interactive data quality dashboard
- 📈 Before/After cleaning comparison
- ⬇️ Download cleaned dataset

## 🛠️ Tech Stack

- **Python**
- **Pandas**
- **NumPy**
- **Streamlit**
- **Plotly**
